# كشكول أمالي القالي (ج١ وج٢)

كشكول رقمي للقراءة والرفقة مع كتاب **أمالي القالي** لأبي علي إسماعيل بن القاسم القالي البغدادي (ت ٣٥٦هـ)، الجزءان الأول والثاني. النص محفوظ حرفياً من المصدر الذي بُنيت عليه النسخة السابقة، مع إعادة بناء كاملة بالمهارة المحدَّثة للكشكول العربي.

التطبيق **ملف واحد** `index.html` فيه كل التنسيق والبرمجة والبيانات، بلا خادم ولا مكتبات ولا خطوات بناء. يعمل دون اتصال بعد فتحه مرة، ويُضاف إلى الشاشة الرئيسية على iPhone.

## ما يحتويه

- **القراءة**: ١٢٧٢ شاهداً موزّعة على ٦٩١ صفحة مدمجة و١٨ موضوعاً، مع رقم موقع ثابت لكل شاهد، وأزرار تنقّل وموضعك وآخر خمسة مواضع.
- **أبيات اليوم**: ثلاثة أبيات ثابتة حسب التاريخ من مختاراتك أو محفوظك، مع إمكانية إخفاء العجز للاستظهار وكشفه باللمس، وستة مسارات قراءة غير اختبارية.
- **مختاراتي**: التظليلات، البطاقات المفضلة، الأبيات المفضلة، قيد الحفظ، المحفوظة، والفوائد — كلها بوصلات تعيدك إلى البطاقة نفسها.
- **بحث**: يتجاوز الحركات، ويجمع بين الكلمة والوسوم (أو)، وفهرس الأعلام، والعودة إلى موضع القراءة الأصلي بما فيه إزاحة التمرير.
- **أدوات القارئ**: مختارات، ثلاث حالات للحفظ، فائدة لكل بطاقة، تصحيح النص مع شارة «معدَّل»، تظليل بملاحظة، حفظ مكان القراءة، ووضع التركيز.
- **التصدير**: JSON احتياطي بمعرّف الكتاب، Markdown، Anki TSV (تصدير فقط — لا اختبارات داخل التطبيق)، وEPUB يُنشأ داخل المتصفح بلا مكتبات.
- **المزامنة الاختيارية**: Gist خاص بPAT من المستخدم، مع دمج حقول آمن وعدم مزامنة الإعدادات أو موضع القراءة.

> ملاحظة منهجية: النص محفوظ حرفياً من المصدر، بما في ذلك الشطر والأخطاء التي قد تكون فيه. الفوائد والتعديلات والتظليل تُحفظ منفصلة في `localStorage` ولا تغير النص الأصلي. لا توجد اختبارات أو درجات داخل الكشكول.

## الاستخدام على iPhone

1. افتح الرابط في **Safari** (ليس في متصفح داخل تطبيق آخر).
2. اضغط زر **المشاركة** ⬆️ ثم **إضافة إلى الشاشة الرئيسية**.
3. افتح الأيقونة من الشاشة الرئيسية؛ سيعمل التطبيق بلا شريط Safari وبصورة standalone.

## النسخ الاحتياطي

كل تقدّمك محفوظ في `localStorage` تحت المفتاح `amali-qali-kashkol-v2` على ذلك الجهاز/المتصفح فقط، ولا يُرفع إلى أي خادم. عند التحديث تُنقل فوائدك ومختاراتك وتظليلاتك وتعديلاتك تلقائياً مرة واحدة من المفتاح القديم `amali-qali-v1`، وتبقى الإعدادات وموضع القراءة من جديد. استخدم **الإعدادات ← تصدير JSON** بشكل دوري واحتفظ بالملف. عند الاستيراد يُرفض أي ملف من كتاب آخر، ويمكن دمج الفوائد وحدها من نسخة أخرى.

## النشر على GitHub Pages

المستودع: `https://github.com/falmalki/amali-qali-kashkol` — الرابط: `https://falmalki.github.io/amali-qali-kashkol/`.

```bash
git clone https://github.com/falmalki/amali-qali-kashkol.git
cd amali-qali-kashkol
cp /path/to/index.html .
cp /path/to/README.md .
git add index.html README.md
git commit -m "إعادة بناء كشكول أمالي القالي بالمهارة المحدثة"
git push origin main
```

ثم في GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch → main / root**.
